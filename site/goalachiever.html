04 / AI mobile app

GoalAchiever

A mobile app that turns a goal described in plain language into a phased roadmap and daily tasks, then adjusts the plan when a task is missed.

Role
Solo build
Stack
React Native (Expo), TypeScript, Zustand, Supabase, PostgreSQL, Gemini API
Links
CodeRésumé (Software Engineer, AI Code Review)

The problem

Long-term goals usually fail in the middle, not at the start. A plan made on day one does not account for the days that go wrong, and most to-do apps just carry a missed task forward without asking why it was missed.

What I built

A mobile app where an AI sets up the plan with you, then keeps adjusting it as real days happen.

  • →Conversational goal setup: the AI rewrites the goal as a clear statement and asks 3 to 5 questions about timeline, current situation and constraints
  • →Roadmap generation with 2 to 3 phases, weekly milestones and daily tasks for the first week, each with a priority and a time estimate
  • →Failure analysis: when a task is missed, the user says why, and the AI categorizes the reason, looks for patterns and reschedules or adjusts the task
  • →Progress analytics with completion rates, failure patterns and 7-day trends

How it works

The three AI features run in Supabase Edge Functions rather than in the app, so the API key never ships to the phone. Every table uses row level security, so a user can only read and write their own goals, tasks and failure history. Missed tasks are stored with their reasons, which gives the AI a history to find patterns in.

Outcome

clarifying questions per goal

The core idea is that a plan should react to missed days, not just record them. Asking why a task failed turns each bad day into information the next version of the plan can use.
