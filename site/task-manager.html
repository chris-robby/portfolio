Full stack task manager

A task manager with a Spring Boot REST API secured with JWT and a React front end, where each user manages their own tasks, priorities and due dates.

Role
Solo build
Stack
Java, Spring Boot, Spring Security, JPA, JWT, React, Vite
Links
CodeRésumé (Full Stack Developer)

The problem

A task list is only useful if it is private. Each person must see only their own tasks, and the API has to enforce that itself, not leave it to the interface.

What I built

A complete application, from database to interface.

  • →A Spring Boot REST API to register, sign in and get the current user, plus endpoints to create, read, update, toggle, filter and delete tasks
  • →Stateless authentication with JWT: a filter checks the token on every request and Spring Security protects the task routes
  • →A JPA data model where every task belongs to a user, with a priority level, a due date and a creation time set automatically
  • →Request validation on DTOs, so the API never exposes its database entities directly
  • →A React front end with protected routes, an authentication context and a dashboard for managing tasks

How it works

The layers follow the standard Spring structure: controllers handle HTTP, services hold the rules, repositories talk to the database, and dependency injection wires them together. Every task is looked up by its ID together with the signed-in user, so nobody can read or change another user's task by guessing an ID.
