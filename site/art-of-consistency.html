The Art of Consistency

A bilingual accountability product with real users, where showing up every day earns your deposit back.

Role
Solo founder and developer
Stack
Next.js, TypeScript, Node.js, PostgreSQL, Stripe, Claude API
Links
Live siteFirst versionRésumé (Full Stack Developer)

The problem

Skipping a habit usually costs nothing, so it is easy to skip. This product puts something at stake: you deposit money against a 21-day challenge and earn it back one day at a time by checking in and writing honestly about how it went.

What I built

I designed, built and run the whole product myself, from data model to payments to the screens people see each day.

  • →Daily check-ins with journaling, where each completed day returns $1 and a skipped day forfeits it
  • →AI feedback on journal entries through two Claude API features: vision OCR and an LLM-driven weekly evaluation, each with scoped prompts
  • →Google OAuth sign-in, and Stripe payments and webhooks for the deposits
  • →Chart.js dashboards so people can see their progress at a glance
  • →A bilingual interface, which grew out of BluePrint, a first version built as a React mobile app

How it works

Jest tests and a GitHub Actions pipeline gate every change. I develop with Claude Code and Codex, guided by a CLAUDE.md I maintain. When an agent gets something wrong, I check its sources, research the question independently and redirect it, rather than trusting the output.

Real people used it and the feedback was positive, but it also showed me what needed work. UI inconsistencies were causing bad experiences, so I fixed them and made the screens less intimidating. The biggest lesson was that real users find problems that tests never will.
